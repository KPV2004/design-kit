Describe an app.
Get a complete, reviewable design project.

A skill for Claude and other AI agents that turns one prompt into wireframes of every screen, a clickable HTML + Tailwind mock with a realtime theme picker, a stand-alone UX spec, dev diagrams and design tokens — all kept in sync when you ask for a change.

บอกไอเดียแอป
ได้โปรเจกต์ดีไซน์ที่รีวิวได้ครบสำหรับส่งทีม dev

Skill สำหรับ Claude และ AI agent อื่น ๆ เปลี่ยนพรอมป์เดียวเป็น wireframe ทุกหน้าจอ, mock แบบคลิกได้พร้อมเลือก theme แบบเรียลไทม์, UX spec ที่ dev เอาไปใช้ได้เลย, diagram สำหรับ dev และ design tokens — แก้ที่ไหน ทุกไฟล์อัปเดตตาม

What you get

One folder, six deliverables, all cross-checked by a script before handover.

Wireframes — every screen

Login, 403/404, empty states, session expired — not just the happy path. Desktop / Tablet / Mobile frames per screen, zoom & pan, 💬 pinned comments, diagrams page.

Clickable mock + theme picker

Hi-fi Tailwind mock (mock.html) with device preview, state switcher and a realtime theme picker — Default / Dark / palette presets from design.md §2.9.

A spec devs implement from

Per-screen state matrix, exact error text, interactions, copy deck (EN/TH), API contract — the spec stands alone, nobody reopens app code.

Dev diagrams

User flow, ER, state and sequence diagrams as Mermaid — synced into the wireframes page and matching the API table exactly.

Design tokens

WCAG-AA-checked palette, tokens.css / tailwind.config.js / tokens.json — plus a platform mapping for Flutter / native constants.

Changes propagate + verify

"Add a phone field" updates every affected file. verify.py checks inventory ↔ wireframes ↔ spec ↔ mock pairing before anything is handed over.

สิ่งที่ได้

โฟลเดอร์เดียว ครบทั้งหมด และมีสคริปต์ตรวจความสอดคล้องก่อนส่งมอบทุกครั้ง

Wireframe — ครบทุกหน้าจอ

Login, 403/404, หน้าว่าง, session หมดอายุ — ไม่ใช่แค่ happy path มี frame Desktop / Tablet / Mobile ต่อหน้า, ซูม-เลื่อน, 💬 ปักหมุดความเห็น และหน้า Diagrams

Mock คลิกได้ + เลือก theme

mock.html แบบ hi-fi มี device preview, สลับ state (ว่าง/โหลด/ผิดพลาด) และเลือก theme แบบเรียลไทม์ — Default / Dark / preset โทนสี จาก design.md §2.9

Spec ที่ dev เอาไปใช้ได้เลย

ตาราง state ของทุกหน้า, ข้อความ error ตรงตามโค้ด, ตาราง interactions, copy deck (EN/TH) และ API contract — spec อยู่ได้ด้วยตัวเอง ไม่ต้องเปิดโค้ดเดิม

Diagram สำหรับ dev

User flow, ER, state, sequence ในรูปแบบ Mermaid — sync เข้าหน้า wireframe และตรงกับตาราง API เป๊ะ

Design tokens

พาเลตตรวจ WCAG AA แล้ว, ออกเป็น tokens.css / tailwind.config.js / tokens.json พร้อม platform mapping สำหรับ Flutter / native

แก้จุดเดียว อัปเดตทุกที่

"เพิ่มช่องเบอร์โทร" แก้ทุกไฟล์ที่เกี่ยวข้องพร้อมกัน โดย verify.py ตรวจว่า inventory ↔ wireframes ↔ spec ↔ mock ตรงกันก่อนส่งมอบ

Install

Claude Code — plugin marketplace recommended

Inside a Claude Code session:

/plugin marketplace add KPV2004/design-kit
/plugin install design-kit@design-kit

Update later with claude plugin marketplace update design-kit + claude plugin update design-kit@design-kit. Invoke with /design-kit:design-kit.

Claude.ai (web / desktop)

Download design-kit.zip from the latest release, then Customize → Skills → + → Upload a skill. Needs "Code execution and file creation" enabled.

Claude Code — manual copy

git clone https://github.com/KPV2004/design-kit.git
cp -r design-kit/skills/design-kit ~/.claude/skills/design-kit

Use .claude/skills/ in a repo to install it there only.

Other AI agents

Standard Agent Skills format — easiest via the skills CLI:

npx skills add KPV2004/design-kit

Or copy skills/design-kit into ~/.agents/skills/ (Codex, Gemini, Cursor, ZCode…). Restart the agent after copying.

Requirements: Python 3.9+ for the helper scripts. Optional: pip install playwright && playwright install chromium enables browser checks (JS errors, icon names, Mermaid syntax, annotation visibility).

Usage

The skill triggers on its own — in English or Thai. For apps with more than ~8 screens it sends you the inventory, flow, palette and icon set to confirm before building anything.

Design a purchase-order approval system for a factory:
list, detail, approve/reject, dashboard.
Users are office staff who use Dynamics AX all day.
ออกแบบแอปจดรายรับรายจ่ายบนมือถือ
มีหน้าบันทึก สรุปรายเดือน และตั้งงบประมาณ
สีหลักเป็นสีส้ม แล้วทำ mock พร้อมเลือก theme ให้ด้วย

To change something, just say it: "เปลี่ยนสีหลักเป็นเขียว", "add a Tablet layout", "remove the dashboard" — every affected file is edited and the version is bumped. Reviewers pin 💬 comments in the wireframe and export them as markdown; Claude applies each item and answers the questions.

วิธีใช้

skill ทำงานเองเมื่อขอให้ออกแบบ — ไทยหรืออังกฤษก็ได้ ถ้าแอปมีมากกว่า ~8 หน้าจอ จะส่ง inventory, flow, พาเลต และชุด icon มาให้ยืนยันก่อนลงมือสร้าง

Updating the skill

Marketplace install

claude plugin marketplace update design-kit
claude plugin update design-kit@design-kit

claude.ai upload

Rebuild with ./tools/build-skill.sh, then replace the upload in Customize → Skills.

Manual copy

rsync -a --delete --exclude '__pycache__' \
  skills/design-kit/ ~/.claude/skills/design-kit/

Then restart the agent — skills load at startup.

Existing design projects

Projects carry their own _tools/ and _engine/ — refresh with cp skills/design-kit/scripts/*.py <project>/_tools/.
